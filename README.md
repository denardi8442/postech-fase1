# Tech Challenge — Fase 1: Pipeline Preditivo de Churn

Projeto de Machine Learning para prever churn de clientes de uma operadora
de telecomunicações, utilizando Scikit-Learn e servido via API com FastAPI.

## Estrutura do projeto

- `data/` — dados brutos e processados
- `notebooks/` — notebooks de exploração e experimentação
- `src/` — código produtivo (pré-processamento, modelo, API)
- `models/` — modelos treinados salvos (.joblib)
- `tests/` — testes automatizados (pytest)
- `docs/` — documentação (ML Canvas, Model Card, enunciado do desafio)
